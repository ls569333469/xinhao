# 1004｜统一工作台布局跳动修复方案

更新日期：2026-10-17（Asia/Shanghai）  
状态：已按本方案改生产前端（CSS/极少 JS）；硬刷即可，不重启服务。

## 1. 背景与用户现象

统一信号工作台里，勾选信号或改组合方式时，右侧「导出当前筛选 CSV」整行会被往下顶，表格跟着跳。全部命中、多选标签时最明显；切「至少N项」、展开「范围选项」也会整页下移。窄屏更晃。

## 2. 根因结构（结果区纵轴）

```
.results
  ├── .quick          （快捷筛选，高度基本稳）
  ├── #u-chips.filterchips   ← 主因：flex-wrap + 动态 chip，高度随勾选膨胀
  ├── .tabletools     ← 导出 CSV / 命中分段 / 排序；自身 wrap 会再折一行
  └── .tablewrap      （表格）
```

左侧旁路：

- `#u-nWrap`：非 N 模式用 `hidden` 直接卸掉高度，切「至少N项」左侧突然增高。
- `#u-scopePanel`：展开占满 `.topfilters` 一格，整页（含 `.shell`）下移；窄屏 `.scope-entry>span{flex-basis:100%}` 摘要强制换行再顶一截。
- 信号原位展开：宽屏主要撑侧栏；窄屏 `shell{display:block}` 时可能顶结果区——本轮只做轻量 max-height。

## 3. 修复原则

1. **交互区高度稳定**：chip 行、工具行、N 输入槽高度不随内容突然增减。
2. **增长内容区内消化**：横向滑或区内滚动，不挤下面栏。
3. **展开面板尽量不推主内容**：范围面板用叠层（overlay），Esc 仍关闭。

## 4. 逐项改法与文件

| 项 | 改法 | 文件 |
|---|---|---|
| A filterchips | `flex-wrap:nowrap` + `overflow-x:auto` + 固定一行高度；chip 不收缩 | `design/unified-workbench.css` |
| B tabletools | `nowrap` + 横向滑 + `min-height`；segment/sorttools 不把导出主键挤飞 | 同上 |
| C nWrap | 始终占位；非 N 用 `visibility:hidden` + `aria-hidden`，勿用 `hidden` 卸高度；控件不可聚焦 | `unified-workbench.js` + CSS |
| D scope | 面板 `position:absolute` 叠在 topfilters 上；去掉窄屏摘要强制整行；scope-entry 最小高度 | CSS；Esc 逻辑沿用 |
| E 信号展开 | 展开区 `max-height` + 区内滚；不改「点名称展开」语义 | CSS |
| A档（可选） | 本轮未大改 A 页；托盘已有 max-height 可对照，toolbar 与本次不同源，避免顺带重构 | — |

## 5. 验收

- 勾选 1～多个信号时，导出栏垂直位置基本不动（chip 过多时横向滑）。
- 切「至少N项」↔「全部/任一」左侧高度不跳。
- 展开范围选项：主内容（`.shell`）不被顶开；Esc 关闭。
- 硬刷统一工作台页（常见 `8767` / `8768` 对应服务页）后看；纯前端，一般不需重启。
