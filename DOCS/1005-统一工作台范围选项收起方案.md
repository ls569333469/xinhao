# 1005｜统一工作台范围选项收起方案

更新日期：2026-10-17（Asia/Shanghai）  
状态：已按本方案改生产前端（HTML/CSS/JS）；硬刷即可，不重启服务。

## 1. 背景

用户觉得顶部「事件归属 / 查看数据 / 合约范围 / 资产映射」难懂、占地方。日常筛币几乎不改这些默认值，却要先猜「范围选项 ▾」再展开，压迫感强。

与现网关系：

- **1001 UI-22**：保留范围能力与验收口径，本方案只改展示层级，不推翻范围语义。
- **1004**：曾把范围面板改成 overlay，减轻展开时整页顶飞。本方案改为默认收起的「高级范围」；展开用文档流内联（`details`），日常关闭时不占结果区高度，也不再依赖叠层入口。

## 2. 决策（白话）

| 项 | 决定 |
|---|---|
| 主行 | 只留：搜索、市场、市值、快捷组合（含组合用法 / 保存） |
| 四项范围 | 全部默认藏进「高级范围」，需要时再展开 |
| 能力 | 不删逻辑；`data-scope` / hidden inputs / JS state 仍绑定 |
| 默认值 | 不变：`history=all`、`context=latest`、`listing=current`、`trusted=false` |
| 预览 C | 仅作折叠思路参考；**不**把两个 checkbox 提到主行（四项全藏） |

## 3. 文案

- 入口：`高级范围`（`details` 的 summary，默认 closed）
- 展开后白话图例：
  - 事件从哪来（原「事件归属」）
  - 用哪份存档（原「查看数据」）
  - 合约是否含历史（原「合约范围」）
  - 市值映射（原「资产映射」）
- 各组保留一句短说明；「恢复范围默认」放在高级面板内。
- 默认收起时**不**再堆一长串灰字摘要；仅在四项偏离默认时，在 summary 旁用很淡的短提示（如「已改范围」），避免压迫。

## 4. 实现要点

### 4.1 HTML（`design/unified-workbench-fragment.html`）

- 去掉「范围选项 ▾」按钮 + 依赖 `hidden` 的叠层入口压迫感。
- 改为 `details.scope-adv#u-scopeAdv`，内含原四组 fieldset / radio / hidden input / 恢复按钮。
- 保留 `#u-scopePanel`、`#u-scopeSummary`、`#u-scopeReset` 与全部 `data-scope`，便于 JS 少改。

### 4.2 CSS（`design/unified-workbench.css`）

- 主行列宽沿用 1004 的 topfilters（搜索 / 市场 / 市值 / 组合），减少右侧大空白。
- `.scope-adv` 占满一行；summary 低调（teal 链感、字号略小）。
- 面板改回文档流内联（取消 1004 的 `position:absolute` 叠层），因默认 closed，日常不顶页；展开时允许自然下推（高级偶发操作可接受）。
- 清理仅服务于旧 toggle/overlay 的 `.scope-entry` 强制样式冲突项。

### 4.3 JS（`design/unified-workbench.js`）

- `syncScope`：继续同步 radio 与 state；摘要改为默认空，非默认时短提示。
- 删除 `#u-scopeToggle` 点击、点外部关闭、Esc 关叠层等与新结构冲突的逻辑。
- Esc：若高级 `details` 打开则关闭并聚焦 summary（顺手清理）。
- `scopeReset`、chips、`change` / 筛选语义不动。

## 5. 验收

1. 默认打开顶部：看不到四组范围单选；主行仅搜索／市场／市值／组合。
2. 点「高级范围」才出现四组；改选项后筛选仍生效。
3. 芯片「已生效条件」仍能反映非默认范围（仅前向、含历史合约等）。
4. 「恢复范围默认」在高级内可用，恢复后与默认一致。
5. 硬刷 `8767` / `8768`（或当前统一台端口）即可，**不重启**扫描／观察服务。

## 6. 约束

- 不改 signal-catalog、strategy-registry、A 规则四文件。
- 不开 scan / observe；不交易。
