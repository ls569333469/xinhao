## 1. 问题（白话）

现在顶栏「挤」主要来自这几块叠在一起：

1. **快捷组合下挂两条链**：「组合用法」「保存组合」——窄屏或四列拉开后容易在组合列里换行，视觉脏、还占高。
2. **黄条 `demo-note`**：整段说明常驻，占一整行高度。
3. **扫描状态 `u-scanStatus`**：大段文案挤在左侧，和标题区抢视线。
4. **快照时间**：`extra-top` 里 `#u-contextLabel` 等单独占一行/半行，再挤左。
5. **筛选四列**：网格未吃满可用宽度时，左侧挤、右侧空。

群里已选定预览 **C · 极简**，要求按 C 的信息层级落地，字号/边距对齐现网，不要缩成窄预览卡。

---

## 2. 决策（选定 C）

| 项 | 决定 |
|---|---|
| 顶栏两链 | **去掉**「组合用法」「保存组合」，不再挂在快捷组合下 |
| 组合用法 | **删除入口即可**；`unified-strategies.html`（策略说明）已有「组合怎么用」 |
| 保存组合 | **能力保留**：入口挪到**左侧信号栏底部**（勾选信号后更合理）；**不删** `#u-saveComboDialog` / 保存逻辑 / localStorage |
| 黄条 demo-note | 默认折进可点的「说明」折叠（或极简一行）；不要大块黄条占高 |
| 扫描状态 | 做成细 **pill／一行状态**，不要大段挤左 |
| 快照时间 | **只**出现在「高级范围」summary 的淡提示里（1005 已有 `#u-scopeSummary`）；不要单独占一行挤左 |
| 筛选四列 | grid **全宽**拉满；主行仍是搜索／市场／市值／组合 |
| 高级范围 | 保持默认**收起**；筛选语义与默认值不变（同 1005） |
| 字号边距 | 对齐现网工作台，按全宽比例落地；预览卡比例仅作信息层级参考 |

默认值不变（承接 1005）：`history=all`、`context=latest`、`listing=current`、`trusted=false`。

## 3. 补记：组合用法删、保存组合迁侧栏

### 3.1 组合用法

- 删除顶栏 `#u-comboHelp`（及 `.combo-tools` 内该链）。
- JS 里 `updateComboHelp` / `previewUpdateComboHelp` 若只为给该链写 `href`：改为仅更新「策略说明」导航（`#u-strategiesNav`）即可，或对已删节点做空判断，避免报错。
- 用户要看组合说明 → 顶栏「策略说明」/ `unified-strategies.html`。

### 3.2 保存组合迁侧栏

- **保留**：`#u-saveComboDialog`、确认/取消、校验、写入自定义组合、刷新下拉等现有逻辑。
- **挪入口**：从顶栏 `#u-saveCombo` 移到左侧 `aside.rail#u-rail` 底部（现有 `.railbottom` 区域或紧邻其上方新增一钮）。
- 建议交互（落地时可微调，需在验收里可点通）：
  - 有勾选信号时入口可用；未勾选时可禁用或点后提示「请先勾选信号」。
  - 点击仍调用现有打开 dialog 的逻辑（与现 `$('saveCombo').onclick` 等价）。
- **不要**把保存能力删成「只能去策略说明页」；侧栏是正式入口。

## 4. 实现要点（确认后再改代码）

### 4.1 HTML（`design/unified-workbench-fragment.html` **与** `design/prototype.html`）

8768 吃 prototype，务必两边齐（1005 补记教训）。

- 快捷组合列：去掉 `.combo-tools` 内「组合用法」「保存组合」；组合列只留 select。
- `demo-note`：改为 `<details class="intro-fold">`（或等价）默认收起，summary 文案如「说明」；展开再看原黄条内容。或收成极简一行——以预览 C 为准，优先折叠。
- 扫描状态：结构可保留 `#u-scanStatus`，外包/改 class 为 pill 一行（具体 class 名落地时与 CSS 对齐）。
- 去掉 `extra-top` 里单独挤左的快照时间展示（如 `#u-contextLabel` 常驻「保存快照」行）；自定义市值输入仍可按需出现，但不要为时间单独占行。
- `details#u-scopeAdv` summary：继续用 `#u-scopeSummary` 显示淡提示（含快照时间／存档语境）；默认 closed。
- 侧栏：在 `#u-rail` 底部增加「保存组合」按钮（建议仍用 id `u-saveCombo`，便于 JS 少改；若 id 变更须同步 JS）。

### 4.2 CSS（`design/unified-workbench.css`）

- `.topfilters` 四列 grid：`width:100%`，列宽参考预览 C：`minmax(180px,1.5fr) + 三列 minmax(140px,1fr)`（或等价全宽分配），消除右空。
- 去掉/弱化依赖顶栏 `.combo-tools` 换行的样式。
- `.demo-note` 大块黄条样式改为折叠体或一行；对齐现网字号，不要预览卡窄边距。
- `.scan-status` → 细 pill／一行；可与标题行动线并排（参考预览 C 的 `.slim-bar` + `.pill`），但落在现网 `intro`/`topactions` 结构上，勿整页改成窄预览壳。
- `.scope-adv-hint` 保持淡色小字；快照时间只走这条。

### 4.3 JS（`design/unified-workbench.js`）

- 去掉对已删顶栏链接的硬依赖（`comboHelp` 节点不存在时不抛错）。
- 侧栏「保存组合」接线：沿用现有 dialog 打开/保存流程。
- `syncScope`（及写入语境文案处）：把快照时间／「保存快照 + 最新归档」类提示写进 `#u-scopeSummary`；**不要**再写到顶栏单独一行。
- 扫描状态文案可缩短为 pill 可读长度；完整说明可放 title 或折叠说明里。
- 不改筛选语义、不改默认范围、不动 scan/observe/AI/交易计划开关。

## 5. 验收点（确认并落地后）

1. 硬刷 `8767` / `8768` 根页：`#u-topFilters` 内**无**「组合用法」「保存组合」文案。
2. 有「高级范围」；默认收起；展开仍见四组范围；默认值与 1005 一致。
3. 筛选主行四列视觉上吃满可用宽度（无明显右空）。
4. 无大块常驻黄条；「说明」可点开或仅极简一行。
5. 扫描状态为细 pill／一行，不占大段左栏。
6. 快照时间只在高级范围 summary 淡提示中出现；顶栏无单独时间行挤左。
7. 左侧信号栏底部能找到「保存组合」；勾选信号后可打开原保存对话框并保存成功。
8. **不重启**扫描／观察服务；不改交易计划相关开关。

线上核对可用：对根页 HTML 计数「组合用法」「保存组合」在 topfilters 片段中应为 0；全页「保存组合」可因侧栏入口仍为 1。
