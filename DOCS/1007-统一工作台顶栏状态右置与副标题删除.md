承接：

- **1006**：顶栏无组合两链、保存组合在侧栏、说明折叠、扫描 pill、筛选四列全宽、快照时间只在 `#u-scopeSummary` —— **本方案不推翻**。

## 1. 问题（白话）

1006 落地后顶栏仍偏「左挤」：

1. **副标题** `统一选信号与组合 · 全部结果同页滚动查看`（intro 下 muted）占左栏一行，信息重复，视觉噪音。
2. **扫描状态 pill**（`#u-scanStatus`）与 **「说明」折叠**（`.intro-fold`）仍落在 intro **下方整行**，和左侧标题区抢纵向空间，不是和右侧操作按钮同侧对齐。
3. **扫描进度条**真实节点是 `#liveScanProgressWrap`（由 `tasks-runtime.js` 创建；统一台在 `unified-workbench.js` 的 `syncScan` 里把它 `insertAdjacentElement('afterend', …)` 挂到 `#u-scanStatus` 旁）。非扫描时可能 `hidden` 看不到。若状态节点仍在左侧/整行，进度条也会跟着掉回左侧挤着。

群里刚定：删副标题；状态 pill + 说明挪到**标题行右侧**；进度条继续挂状态旁且落在右侧状态区。

---

## 2. 决定

| 项 | 决定 |
|---|---|
| 副标题 muted | **删除**文案「统一选信号与组合 · 全部结果同页滚动查看」；intro 左侧只留「统一信号工作台」标题 |
| 扫描状态 pill | 挪进标题行**右侧**，与顶栏操作按钮同侧 / 对齐 |
| 「说明」折叠 | 一并挪到标题行右侧（紧邻状态 pill） |
| 扫描进度条 | 挂载逻辑仍指向 `#u-scanStatus` 旁；落地后物理位置在**右侧状态区**内/旁，勿再掉回左侧整行 |
| 1005 / 1006 | **不推翻**：高级范围默认收起、顶栏无组合两链、保存组合在侧栏、筛选四列全宽、快照进 summary 等保持 |

默认值不变：`history=all`、`context=latest`、`listing=current`、`trusted=false`。

## 3. 进度条位置（写进方案）

- **真实进度 UI**：`#liveScanProgressWrap`（内含 `#liveScanProgressBar` / `#liveScanProgressText` / `#liveScanProgressTime`），由 `design/tasks-runtime.js` 注入任务控件时创建。
- **统一台挂载**：`design/unified-workbench.js` 在 `syncScan` 中：若 meter 的父节点不是 `#u-scanStatus` 的父节点，则 `$('scanStatus').insertAdjacentElement('afterend', meter)`，并微调 flex/宽高边距，避免占满左侧。
- **可见性**：仅扫描 `queued` / `running` 时 `updateProgressMeter` 取消 `hidden`；平时可能看不到，属正常。
- **本轮要求**：DOM 上 `#u-scanStatus` 已在右侧状态区后，`afterend` 自然落在右侧；必要时收紧 meter 的 inline 宽/边距（相对 1006 的 `calc(100% - 36px)` + `margin:8px 18px`），避免再当整页左缘条带。

尽量**只调统一台布局**（fragment / prototype / css / unified-workbench.js）；`tasks-runtime.js` 只读确认挂载点，非必要不改。
