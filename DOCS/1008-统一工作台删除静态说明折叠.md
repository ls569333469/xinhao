## 1. 问题（白话）

1007 把「说明」折叠（`details.intro-fold`）挪到标题行右侧后，点开会**撑开右侧**，把顶栏操作按钮和状态区挤歪、错位。

这段「说明」里的文案是旧常驻提示：

> 真实保存快照与独立策略归档 · C及新增辅助未接入 · 不自动启用任务

它**不是**健康检查，也**不是**加载失败提示。系统正常时不该再占顶栏。

加载失败 / BUG 另有通道：

- 顶部错误条：`unified-workbench.js` 里 `统一工作台加载失败：…`，节点 class `.u-error`
- 扫描状态 pill：`#u-scanStatus`（及扫描时挂在旁的进度条）

不要用「说明」折叠承载报错。

## 2. 决定

| 项 | 决定 |
|---|---|
| 顶栏静态「说明」折叠 | **删除** `details.intro-fold` 及其内 `demo-note` 文案；系统正常时不显示 |
| 加载失败 / BUG | **继续**用现有 `.u-error` 顶部错误条 + `#u-scanStatus` pill；不用说明折叠 |

| UnifiedCore / 加载链 | 现网 `/unified-core.js` 可正常返回、脚本顺序正确；**本轮以删说明为主**，不顺便大改加载链；仅当删说明时发现明显挂载错误再最小修复 |
| 1005–1007 | **不推翻**：高级范围、无顶栏组合链、侧栏保存、四列全宽、状态右置、无副标题 |

默认值不变：`history=all`、`context=latest`、`listing=current`、`trusted=false`。
