# 1009｜统一工作台扫描状态全文显示

---

## 1. 问题（白话）

雪球截图：状态 pill 显示到「常规4H：部」就断了，完整文案（来自 `tasks-runtime.js` 的扫描摘要）看不全。

根因有两层（都改）：

1. **脚本硬切**：`unified-workbench.js` 的 `syncScan` 里 `if(short.length>36) short=short.slice(0,34)+'…'`，长状态被砍到约 36 字。
2. **CSS 限宽**：`.intro .scan-status` 使用 `max-width:min(280px,46vw)` + 全局 `white-space:nowrap; overflow:hidden; text-overflow:ellipsis`，窄屏还会再省略。

`title` 虽有全文，但主文案不应靠悬停才能读完。

---

## 2. 决定

| 项 | 决定 |
|---|---|
| JS 硬切 36 字 | **去掉**；`textContent` 写完整 `status`；`title` 仍写全文（悬停兜底） |
| intro 区 pill 宽高 | **放宽**：去掉/大幅提高 intro 内 `max-width:280px`；允许换行显示全文 |
| 全局 pill 样式 | `white-space` 改为可换行；保留 pill 圆角与配色；极窄屏仍 `max-width:100%` |
| 进度条 | 仍挂在 `#u-scanStatus` 旁；不改进度逻辑 |
| 文案内容本身 | **不改** `tasks-runtime.js` 摘要句式（本轮只修显示截断） |
| 1005–1008 | **不推翻** |
