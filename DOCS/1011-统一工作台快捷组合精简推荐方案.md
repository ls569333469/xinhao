## 1. 问题（白话）

雪球反馈：快捷组合「不太科学」。对照最新文档后，主要问题是：

1. **旧胜率故事还在暗示**：早期 v3.0「S1～S5 高胜率排名」已撤回，但下拉里仍混着观察项、演示项、未接入项，看起来像「都推荐」。
2. **编号语义打架**：旧 S1 的⑤是「量能确认」，工作台⑤是「聪明钱」；旧 S3 的⑥是「1H 背离」，工作台⑥是「24H 量增价平」。名字像同一套，实际不是。
3. **有效策略与入口不对齐**：
   - A 有效 → 应突出「中/强确认」与「候选观察」
   - B 有效 → 应突出待确认 / 已确认，而不是用⑥冒充
   - C 未接入 → 不应和常用推荐并列成「可点真信号」
4. **过松 / 过严都误导**：「不限制信号」「六项同时满足」「EMA／B／C任一」会把筛选意义冲淡，或几乎筛空，却占着「推荐」位。

本方案目标：在**不改 A/B/C 判定规则**的前提下，重排快捷组合的**分组、默认可见项、文案与排序**，让「推荐」只指向现行有效观察路径。

## 2. 原则（冻结）

| 原则 | 说明 |
|---|---|
| 组合≠策略 | 组合只同步勾选/阶段/阈值；不改写 A/B/C 归档、确认、退出 |
| 不恢复旧胜率 | 说明里禁止写「胜率 xx% / 平均涨幅」；可写「对应旧 S1 意图（已撤回数字）」 |
| 语义诚实 | ⑥永远是 24H；B 永远用 B 身份；⑤永远是聪明钱，不是 A 量能 |
| C 不装完成 | C 组合保留但标「规划 / 未接入」，移出「推荐」组 |
| 可回退 | 旧组合 ID 不删除，可进「更多 / 历史」；涉及④语义的继续用独立 ID（已有 `*_v32`） |
| 先审后改 | 本文件审阅通过后再改 `unified-combos.js` / 说明页；默认不自动启用任务或 AI |

默认范围不变：`history=all`、`context=latest`、`listing=current`、`trusted=false`。

## 4. 提议的新分组与排序

### 4.1 推荐（默认展开，约 5～6 项）

按「先结构、再 A、再 B」排列：

| 顺序 | 建议显示名 | 现有 id（沿用） | 条件摘要 | 用途一句话 |
|---|---|---|---|---|
| 1 | ①②④ EMA中/强确认 | `a_confirm_v32` | ①② AND ④中/强 | 现行 A 主观察（旧 S1 意图） |
| 2 | ①②④ EMA候选观察 | `a_candidate_v32` | ①② AND ④活跃候选 | 跟踪 A 池，非入场 |
| 3 | ①② 杠杆＋账户拥挤 | `leverage` | ①② | 蓄力观察，等金叉/B |
| 4 | 放量价稳 · 已确认（B） | （现有 B 已确认 id） | B 完整资格确认 | 现行 B 主观察 |
| 5 | 放量价稳 · 待确认（B） | （现有 B 待确认 id） | B 待 h+1 | 等下一小时确认 |
| 6 | ①②＋放量价稳待确认 | （现有 ①②＋B id） | ①② AND B 待确认 | 结构＋B 早期（旧 S3 意图） |

说明文案统一加一句：**「组合只筛选列表；旧胜率数字已撤回。」**

### 4.2 更多观察（默认收起）

保留但降级，避免占「推荐」心智：

- ①②③ 空头拥挤观察（③为辅助勾选）
- ②③ 账户＋费率
- ③⑥ 负费率＋量增价平（注明⑥≠B）
- ④⑥ EMA确认＋量增价平（注明⑥是 24H）
- 聪明钱＋放量价稳确认（注明无收益验证）
- 六项同时满足（当前④）（极严，研究用）
- 不限制信号（清筛选用，可放组末或工具位）

### 4.3 规划 / 未接入（默认收起，灰色或「未接入」标记）

- 超卖反弹候选（C，规划）— `available` 可仍为 true 以便点选看到空态说明，但**必须**显示未接入，不得暗示有生产信号
- S2 金叉已形成、量待确认 — 保持 `available:false`
- EMA／B／C任一 — 降为演示/研究；从推荐移除（或改名「研究：任一命中」并注明无收益验证）

### 4.4 不建议本轮删除的 ID

全部保留 id 与历史自定义引用；只改 `group`、排序、`purpose`/`risk` 措辞、默认折叠。避免雪球已存自定义组合断链。
