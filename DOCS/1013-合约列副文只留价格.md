# 1013｜合约列副文只留价格

更新日期：2026-10-18（Asia/Shanghai）  
状态：**已落地**（2026-10-18 Asia/Shanghai）

## 问题

统一台合约列副文写成 `COIN-M · USD` + `快照 5.021 USD`；`.secondary` 未块级时粘成「USD快照…」。「快照」是方案/数据口径用词，不应出现在主表副文。

## 决定

合约列：**代币名 + 一行价格**（数值 + 报价币；历史合约仍带「历史合约」）。去掉市场类型（COIN-M / USDⓈ-M）与「快照」字样。详情抽屉身份行仍可保留市场信息。

## 改动

| 文件 | 动作 |
|---|---|
| `design/unified-workbench.js` | `rowHtml` 合约列副文只留价格 |
| `design/market-evidence.js` | 共享 symbol 单元格同步；列名改为「合约 / 价格」 |
| `design/pro-table-runtime.js` / `prototype.html` | 专业表合约副文去掉市场类型前缀 |
| `design/unified-workbench.css` | `.secondary` 块级展示 |

## 验收

硬刷后合约列形如 `NEARUSD_PERP` 下一行 `5.021 USD`（或等价价格格式），无「快照」「COIN-M ·」粘连。
