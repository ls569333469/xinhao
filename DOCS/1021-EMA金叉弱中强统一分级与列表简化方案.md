# 1021｜EMA金叉弱中强统一分级与列表简化方案

日期：2026-10-20。用户已批准分级方向，并授权复核、DOCS排序和代码更新。承接1020；本方案明确替代1020“独立交叉不分级”的市场展示口径。

## 1. 范围和唯一口径

市场④统一采用版本化技术分级 `ema-technical-grade-v1`：左侧显示全部、弱观察、弱、中、强、中＋强；列表、计数、排序、详情和导出共用同一个纯计算函数。输入只读已保存的闭合4H EMA及同期量能，不请求行情、不修改历史快照。

原 `ignitionGrade`、A候选资格、T/T+1周期确认与退出账本保留为原策略证据，不被市场技术等级覆盖。原①②等持仓条件、B/C、调度及自动补齐均不因该显示分级改变。技术强信号不能写成原A策略资格已通过。详情明确区分两套证据的名称，主表只显示本方案技术等级。

## 2. 复核后冻结规则

三个交叉均只做向上：前根短线≤长线，本根短线>长线。两个相邻闭合4H根均需满足既有连续预热；不跨缺口，不用实时未闭合价格。所有均线明确为EMA7/25/99，不混用MA99。

| 触发类型 | 当前收盘结构 | 等级 |
|---|---|---|
| EMA7上穿EMA25 | EMA7≤EMA99，尚未突破99 | 弱 |
| EMA7上穿EMA25 | EMA7>EMA99，尚未形成完整排列 | 中 |
| EMA7上穿EMA99 | 尚未形成完整排列 | 中 |
| EMA25上穿EMA99 | EMA7未高于EMA25，尚未形成完整排列 | 中 |
| 以上任一新交叉 | EMA7>EMA25>EMA99，4H量比<2 | 中 |
| 以上任一新交叉 | EMA7>EMA25>EMA99，4H量比≥2 | 强 |
| 价格新上穿各自EMA99，且无上述均线交叉 | 价格突破已证实 | 弱观察；类型明确写价格突破，不能写7穿99 |
| 无新交叉，仅保持完整多头排列 | 持续结构 | 无本根新信号；写多头排列持续，不重复产生强 |

同根有多个均线交叉，合并一个合约/4H根事件，保留所有类型，按上述最高等级显示；不按交叉数量重复计数。新形成完整排列至少有一个新向上交叉，持续排列不以本根放量重新造事件。

量比采用本根4H成交量/此前7根4H平均量；前7根不含本根，单位与原合约一致。不得用24H量倍数代替。量比等于2达标，EMA相等未上穿；前根相等、本根严格高于可成立。

突破/完整排列已证实但缺同期量能：显示中＋量能待核，不提升强；强筛选返回待核，不能据缺数判明确未命中。若位置、时点或相邻交叉证据缺失，等级待核，不塞进弱。量比0有效、负数/NaN/Infinity无效。原A旧等级不替代缺失的新分级证据。

## 3. 列表和详情

列名与快捷入口统一“EMA金叉 · 4H”。主表三行：第一行弱/中/强（缺量附量能待核）；第二行具体EMA交叉名称，同根多交叉合并；第三行实际4H开收时间，统一北京时间，明确已收盘。量比和等级依据在详情可查，弱价格突破明确“弱观察”。无信号显示无新信号/多头排列持续；未知显示数据待核。

本根使用该行 `candleAsOf` 对齐的观察，不能套扫描开始/结束时间。时点不同拒绝混合；最近60根交叉列表单独标历史，按各自EMA和各自量比分级，不用当前根量比或当前等级覆盖过去。同一根合并展示，历史窗口不足明确说明，不宣称全部历史覆盖。

左侧和等级设置显示全部、弱观察、弱、中、强、中＋强。弱观察仅匹配价格新穿EMA99；弱仅匹配99下7穿25，两者互斥；全部包含二者与中强，中＋强为中与强的并集（缺量暂定中也纳入）。不再展开交叉类型/完整排列/候选/确认按钮。详情保留交叉值、原A候选与后续确认状态。合法旧已保存查询和命名组合保留原条件，并清楚标注兼容含义；选择新版六档才主动切换。损坏或无效查询整笔拒绝，不部分应用或改成全部。

筛选/摘要/计数/排序/导出一致；导出同时保留新技术分级版本、实际K线时间、交叉类型、量能状态、原A等级。基础行情读取中已有数据保留，继承1020空表修复。实际HTML内嵌脚本与独立资源同步发布。
