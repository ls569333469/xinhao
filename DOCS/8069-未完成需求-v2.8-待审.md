## 0. 锁定的 V1 首验路径（停撒 deepen，先锁闭环）

雪球 + GPT 审计共识：**先锁第一条可验收主链路**，暂停零散加深刀。

```
扫描 → 报告 → 冻结策略 → USDT 纸面模拟 → 定期结算复盘
```

| 步骤 | 最小要能做什么 | 当前口径 |
|---|---|---|
| 扫描 | 本机跑扫描，拿到 snapshot/revision | 可用；覆盖仍可能 partial |
| 报告 | 基于快照出报告（本地/AI 分标） | AI-03 可点验；须防扫描失败偷用旧快照 |
| 冻结策略 | 草案→冻结；跨页同指纹；导入不可篡改规则却沿用旧 hash | **P1/P2 已修**（见下）；观察层六阈值镜像仍未齐 |
| USDT 纸面模拟 | 共享/对照账户、事件账本、预算硬闸、手填/autofill | 纸面可用；**全自动撮合未齐** |
| 定期结算复盘 | 前向结算 + 数值复盘计划 | 半自动可走；全市场自动观察/补查后再 settle、付费 AI 叙述未齐 |

**V1 明确不纳入本轮验收**：可信 ATH、全历史上市宇宙/下架样本、USDC/COIN-M 模拟引擎、精确⑤真源预置（见「后续版本」）。

### 审计已修缺陷（2026-10-13）

| ID | 问题 | 修复 |
|---|---|---|
| **P1 RULE-IMPORT-HASH** | 导入包可改 `rules` 却保留声明 `content_hash`/指纹，仍返回 `fingerprint_verified=true` | 按实际 rules+deps+meta **重算** content_hash，与声明不一致 → 409；改名时显式记录 `source_content_hash` / `result_content_hash` |
| **P2 RULE-JOINT-KEY** | freeze/export 的 `unified_key` 截断 hash 16 位，bindings 用全长 → 同版本同覆盖 `joint_hash` 不一致，误拒启用 | `canonical_unified_key` 全长编码；禁止用 `acknowledge_coverage_drift` 掩盖编码不一致 |

| **EVAL-RESETTLE** | 补查完成未自动再 settle；断档可能触价假赢 | candle_range 完成回调+调度轮询再 settle；触价前断档→pending/unverifiable |
| **WARMUP-BYPASS** | 请求可降低 `warmup_bars` / F07 partial 仍放行基线 | 底线+冻结预热不可降（降则 409）；critical 须 covered；断档拒 autofill / scan_and_research / deps |

| **FROZEN-EXEC** | 纸面 autofill / EVAL settle / backtest 可能用草案或静默默认（F04 突破站位）而非冻结 params | `frozen_exec.require_frozen_exec_params`：缺参/歧义→409；SIM/EVAL/backtest 只读冻结；草案改动不生效；禁静默 entry_rule |
| **CONFIG-BACKUP-HASH** | 备份缺 payload 校验；路径可逃逸；pause/并发可静默覆盖 | manifest+payload_hash；篡改/缺 hash→409；restore 禁路径逃逸；pause/revision/package_hash 并发闸 |
| **LOOKAHEAD-GUARD** | 回测/STRUCT 可能用决策后K线或未裁剪公平窗；全窗 min_adx 泄漏未来 | as-of 入场闸；公平窗裁剪；单元格仅预热预检；不足显式排除计数 |
| **V1-API-SMOKE** | V1 路径 API 未对 live 8767/8768 扫通 | 34/34 PASS：scan→freeze→autofill→obs→settle(F02/断档不假赢)→backup hash；脚本见 yidong_stage；**模块仍不标完成**；页面点验未做 |
| **EXT-AUTH-BYPASS** | claim 可省略核验 / 未来 as_of / skip 标志 / 替代源冒充精确⑤ | bypass 旗与未来 as_of→409；claim 须 echo as_of/口径/hash；精确⑤拒储备/技术流登记与 claim；异槽不可 label 为精确⑤；**模块仍不标完成** |
| **AI-F09-VERIFY** | 审计担心证据/schema/缓存/报告指纹未贯通 | 本刀复核：F09+stamp 已挂；15 unittest OK；**无新增修复**；真实能力仍未验证；**不标 AI 完成** |

回归：指纹 P1/P2 + `WarmupBypassHardeningTests`（coverage 套件）；`test_p1_import_refuses_tampered_rules_keeping_declared_hash`、`test_p2_joint_hash_stable_across_freeze_and_bindings`（指纹套件共 20）。

## 5. DATA vs AI：分工

| 角色 | 负责 | 不负责 |
|---|---|---|
| **DATA** | 本地扫描/K 线/revision/覆盖与补查；回答「齐不齐」 | 不写投研结论；不假装精确⑤已齐 |
| **AI** | 显式调用下的连接、检索、叙述；证据引用 | 不替代账本；失败不用旧快照；不编造收益 |

**行情真假看 DATA；文字解释看 AI；revision 必须对得上。**
