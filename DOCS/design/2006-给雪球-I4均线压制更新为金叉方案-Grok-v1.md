## 3. 推荐改法（最小拆分，仍先方案）

### 3.1 原则

1. **不要把 I4 改成金叉**——会毁掉「蓄力池」语义，也违反 requirements「不能同一瞬间既三线下方又上穿」。
2. **I4 保留** = Stage1「三线下方」布尔（可改标题/副文案为「蓄力·三线下方」，id 仍 I4）。
3. **新增点火层**（建议 id：**I4b** 或策略侧 `ignitionGrade`，二选一命名；下文用 **I4b**）。
4. **量能字段拆开**：点火用新字段（如 `barVolumeRatio7`），避免静默改坏 T8/`barVolumeRatio` 历史口径。
5. **classify 状态机**后续再改：先出字段与分级，再决定是否废弃/降级「收盘突破线索」名称。

### 3.2 I4（保留 · 蓄力）

- **仍满足**：已收盘 4H `close < EMA7 且 < EMA25 且 < EMA99`。
- **建议附加（旁路，不塞进同一 True/False 也可）**：
  - `rsi4h`（或 14 周期明确写进 `emaMethod` 同类说明）；
  - `sidewaysOk`：RSI∈[30,55] **且** 近 7 日（或近 N 根 4H）无「持续创新低」；
  - `deathTrend`：持续创新低 → Stage1 **排除**。
- UI：④ 文案改为「蓄力·三线下方」或副标题注明「非入场」；pro-table `ema` 列可加「蓄力/已启动」小状态（实现轮）。

### 3.3 新增 I4b / 启动信号（强中弱）

建议扫描行输出：

| 字段 | 含义 |
|------|------|
| `emaStack` | 当前是否 `EMA7>EMA25>EMA99` |
| `emaStackPrev` | 上一根是否已是完全多头（用于「刚形成」） |
| `ema7Cross25` | EMA7 是否由下上穿 EMA25（用 prior vs current EMA，不是仅看价格） |
| `priceAboveEma99` | 收盘 > EMA99 |
| `ema7Below25` / 死叉 | EMA7 < EMA25（弱信号判定） |
| `barVolumeRatio7` | 当根量 ÷ **前 7 根**均量 |
| **`ignitionGrade`** | `strong` / `medium` / `weak` / `none` |

映射（与手册一致）：

- 🟢 **strong**：`emaStack` 且（建议）`not emaStackPrev` 且 `barVolumeRatio7 ≥ 2`
- 🟡 **medium**：`ema7Cross25` 且 `priceAboveEma99` 且 `barVolumeRatio7 ≥ 2`（允许 EMA25 仍 < EMA99）
- 🔴 **weak**：`priceAboveEma99` 且 EMA7/25 仍死叉（不论是否被旧 `crossEma99` 点亮）
- 其余：`none`

Registry 落点（实现轮二选一，本方案推荐 A）：

- **A**：indicators 增加 `I4b`（展示用分级；规则可用 `op: ignition_grade` + 阈值）；  
- **B**：不进六大勾选，只在详情/策略 T1 触发层读 `ignitionGrade`。

### 3.4 与 ①②③ 的组合（产品叙事）

- Stage1 观察名单：**①② + I4(三线下方) + sidewaysOk**；③ 默认 **bonus**（与手册一致；若保留今日 classify「必须 ①②③」需雪球明确是否放宽）。
- Stage2 入场观察：名单内出现 🟢/🟡；🔴 只打标不推入场。
- T1/T2 触发文案（文档轮）：从「上穿 EMA99」改为「I4b 🟢优先 / 🟡次之；🔴勿当入场」。

### 3.5 EMA99 窗口

- 短期：提高 `limit`（在 API 上限内尽量多），并在 `emaMethod` 写清根数与「非全历史」。
- 中期：按 symbol 缓存更长 4H 历史，EMA 状态可增量更新，逼近手册「完整历史」。
- 验收：抽样币对比 TradingView 同合约 4H EMA99，误差进允许带或标 `emaQuality=short_window`。

### 3.6 明确不做（本方案边界）

- 本文件 **不改** 任何 `.py` / `.js` / `.json` 产品逻辑。  
- 不把 A 档 /「已实现金叉」写进完成态。  
- 不自动交易、不改冻结执行参数。

## 4. 风险

| 风险 | 说明 | 缓解 |
|------|------|------|
| **EMA99 窗口不足** | 300 根初始化 ≠ 全历史；金叉边界币可能和 TV 不一致 | 加长窗口 + `emaQuality`；验收对表 |
| **假突破 / 弱穿线** | 今日「收盘突破线索」大量接近新 🔴 | 分级后默认不把 🔴 当候选升级；文案降级 |
| **静默改 `barVolumeRatio`** | 若把 20→7 会扯动 T8、历史快照、测试 | **新字段** `barVolumeRatio7`；旧字段保留 |
| **I4 与 I4b 同时 True** | 物理上「三线下方」与「价上 EMA99/金叉」互斥 | 状态机分阶段；UI 禁止合成「又压制又突破」 |
| **RSI/横盘误杀** | 阈值拍脑袋可能漏掉真蓄力或放过死亡下跌 | 先只输出字段 + 人工抽检；阈值进配置而非写死不可调 |
| **③ 硬/软门槛** | classify 今日强依赖 ①②③；手册 ③ 为加分 | 需雪球拍板后再改 classify |
| **文档漂移** | ①–⑫ 方案、requirements、ai-review、T1/T2 文案仍写旧点火 | 实现前先改文档口径（可与本方案同批） |

## 5. 验收标准（实现轮才跑；此处先立项）

1. **I4**：随机抽样，三线下方判定与手工/TV 方向一致；标题/帮助文案标明「蓄力非入场」。  
2. **横盘**：RSI、7 日新低规则有单测；死亡下跌样例（持续新低）→ `sidewaysOk=false`。  
3. **I4b 🟢**：构造 `EMA7>25>99` 刚形成 + `barVolumeRatio7≥2` → `strong`；上一根已多头排列 → 不标「刚形成」或降噪策略符合文档。  
4. **I4b 🟡**：EMA7 上穿 25 + 价上 99 + 量≥2×，即使 25 仍在 99 下 → `medium`。  
5. **I4b 🔴**：价上 99 且 7/25 死叉 → `weak`；**不得**再单独因 `crossEma99` 升成强线索。  
6. **量能**：点火路径只用前 7 根；旧 `barVolumeRatio`（20）行为回归不变。  
7. **互斥**：同一行不得同时 `I4=true` 且 `ignitionGrade∈{strong,medium}`（价位逻辑上应互斥；单测锁死）。  
8. **文档**：strategies/01 附录、本方案、requirements/ai-review/①–⑫ 中「时机层=crossEma99」表述已对齐或显式标 deprecated。  
9. **仍不宣称**：回测盈利、A 档完成、自动下单。
