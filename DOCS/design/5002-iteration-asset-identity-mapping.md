# 扫描资产身份映射与指数市值口径修复

依据用户对“待核验是否重名、股票还是加密资产”的排查与解决要求，修复现有扫描映射缺口。

## 数据规则

- asset-mappings.json维护交易所基础资产到CoinGecko项目ID的显式映射、来源URL、链/地址、依据与可信状态。asset_identity.py校验结构并按内容生成版本hash。
- 明确ID优先于同代码候选。固定映射没有有效市值时保留未知，不回退同代码其他项目；目录唯一代码原有获取路径保留候选身份，不自动升级可信度。
- 跨来源地址匹配但期货绑定未充分证明的，允许定向取得候选值，保持capTrusted=false。价格/合约倍数差异闸继续生效。
- 指数的普通单币流通市值及单币OI/市值为“不适用”，与取值失败分开记录，不能匹配同名加密代币。
- 自动扫描沿用现有一次有界补查。CoinGecko维持5×90%=4.5次/分钟保守限速，429后冷却停该轮来源。

## 当前快照迁移

verify_latest新增内部mapping_revision参数，仅接受当前注册目录版本；同版本重复调用不发请求、不发新revision。当前源码新增映射可以对旧快照的缺市值项做一次受控补全，保留ScanLease、归档版本与未发布证据保护。只更新缺市值和必要关联计算，旧行情、已有市值及历史revision保留。此参数不暴露为页面自动触发接口。
