# 给 GROK：A 布局 + C 专业表格的间距与阅读优化建议

用户当前反馈：页面字符与间距过于拥挤，希望恢复之前 A 版的版块间距；完整专业数据继续保留。

## 对照依据与判断

对照用户提供的当前截图、现有 `design/a-shell.css`、`design/pro-table-runtime.js`、`design/prototype.html`，以及项目外 `ux-previews-20261013/version-a-pro-desktop.png` 和原预览源码。没有打开正式页面触发初始化，也没有执行任何扫描/AI请求。以下是源码与截图审查建议，尚未做现网交互验收。

当前基础正文已经是14px，专业表正文12.5px、辅助信息11px。拥挤不只来自字号：

1. 表格 `table-layout:fixed`、`width:100%`、`min-width:0!important` 强制挤入结果区；单元格 `overflow-wrap:anywhere` / `word-break:break-word`，使合约名、价格、百分比和长表头断行。用户截图中的 `AUCTIONUSDT` 已折行，费率说明也堆成多行。
2. 表格外层 `overflow-x:clip!important` 取消横向查看空间。数据列更多时会继续压缩；这与之前专业表允许横向浏览的体验不同。
3. 工具条把“排序、显示列、仅明确映射、已选计数、投研按钮”全部 append 到同一个 right 容器，再与“更多”并排。视觉主次不清，排序与显示列没有留在稳定的右端。
4. 每行反复显示 funding 来源和链上无覆盖的长说明，占据阅读空间。关键数据、状态、解释的字号与层级差异不足。
5. 外壳 CSS 和 runtime 注入 CSS 重复定义相同布局。后注入的高优先级桌面274px规则可能压过窄屏断点，不能靠不断追加覆盖解决。

## 建议目标：默认采用舒适密度

先恢复 A 版的区块节奏，再校正专业表列宽。下列数值为建议目标，不是当前实测结果：

| 区域 | 当前源码 | 建议 |
|---|---|---|
| 主内容留白 | 22px / 24px | 上下26px、左右28px；宽屏左右32–40px |
| 标题区到快照区 | 标题margin-bottom12px | 20px |
| 快照区到工作台 | margin-bottom16px | 20–24px |
| 左筛选与右结果 | gap18px | 24px；沿用独立区块 |
| 筛选卡 / 结果卡内边距 | 14px / 12px 14px | 18px / 18–20px |
| 标签到控件 | 使用既有field gap5px | 6px；控件间距12px |
| 控件触达尺寸 | 按padding7px撑开 | 高度38–40px，字号13–14px |
| 筛选分组 | 竖排连续排列 | 基础条件 / 六指标 / 储备辅助分组，组间16–20px |
| 正文 / 表格数字 | 14px / 12.5px | 14px / 13–14px；行高1.5 |

优先调间距和列宽。主标题24–26px、分组标题14–16px；避免全站统一加大字体导致另一次拥挤。可在之后提供“舒适 / 紧凑”密度切换并保存偏好，默认舒适。

## 专业表格：为完整数据提供宽度

- 26个数据列继续保留在显示列选择器中，默认仍为11个数据列，另加选择与合约两列。列偏好不能因这次调整被清空。
- 为每个字段设置明确宽度，建议通过 colgroup 或 data-col 映射定义。选择40px；合约160px；市值/OI/成交额120–140px；账户比/涨跌100–120px；命中状态130–150px；费率160–180px；EMA150–170px；净流状态160–180px；观测时间190–210px。按实际显示列累加表格宽度，至少等于结果区宽度；宽屏多余空间可分配给文字列。
- 可以继续使用 fixed table layout，但前提是表宽与各列宽度明确，移除强制 min-width:0 的挤压策略。全26列超过视口时，允许表格区域横向滚动，不能靠缩字号或字符折行硬塞。
- 页面本身保持无横向溢出；只有表格的容器使用 overflow-x:auto。保留页面纵向滚动，不给结果表加固定高度的纵向滚动区；GROK应在浏览器核实 sticky 表头与横向容器的兼容性，不能只凭 CSS 声明声称成功。
- 合约名、主要金额/价格/比例、费率数值和单位保持一行；数值右对齐并使用 tabular-nums，状态/说明列左对齐。表头允许在语义分隔处两行，禁止从数字或“USDT”中间断字。
- 固定选择与合约列；第二列 left 与第一列实际宽度一致。表头和固定列交叉处保持正确层级、背景和阴影，横向滚动时不相互覆盖。

## 工具条与信息层级

恢复原 A 版的两层结构：

- 上层：当前条件标签、重置；“仅明确映射”靠近筛选条件。
- 下层：左端为“明确满足 / 待核验 / 已选”页签与数量；右端只放“排序字段 → 方向 → 显示列”。使用左右两组，右组 margin-left:auto；“更多”可收入右端菜单，但不能把排序组留在中间。
- 已选数量与投研操作归入既有底部托盘。保留现有功能和选择状态；不为了搬按钮复制ID或绑定两次事件。托盘不遮挡最后一行和横向滚动条。
- 提示横条缩为“完整专业表格 · 11/26列”，详细表格用法通过帮助入口展开。把当前长串布局说明从默认主路径中移出。

每格以“主数据 + 一行辅助信息”为常规结构。例如资金费率：主行展示年化，副行展示当前费率与周期，两项都保留且标签清晰；完整来源放入可点击/可键盘操作的证据详情。⑤继续显式展示“未知 · 无精确覆盖”，不能改成0或仅用颜色。全表共同的无覆盖说明放在公共提示中；单个对象不同的缺失原因必须在该对象详情中保留。市值“映射待核对”仍显示，不可为清爽删除。
