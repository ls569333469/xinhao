| 项目 | 用户已确认规则 |
|---|---|
| 完全金叉 | 当前已收盘4H：EMA7>EMA25>EMA99；上一根EMA25≤EMA99 |
| 量能 | 本根量/前7根均量≥2，均值不含本根；当根或紧接下一根确认，不能等t+2 |
| 候选期限 | 入池起30天，非持仓期限；突破三线不直接删除候选 |
| OI出池 | 当前同合约美元OI < 入池美元OI×70%，基数不重置 |
| 持续新低 | 最新10根4H收盘，至少3次低于窗口内此前收盘最低值；首根只作基准 |
| 横盘过滤 | RSI14 Wilder 30–55；过去20根最高high/最低low <1.35；1.5是后续研究选项 |
| 初始止损 | 金叉根EMA99，延迟放量不改成确认根EMA99 |
| 止损触发 | 4H收盘低于此前有效止损线，下一根可执行开盘出场；盘中触价不触发 |
| 追踪止损 | 首次入场后4H收盘高于实际入场价才激活，之后max(旧止损,当根EMA99)，只升不降；先判断旧止损再更新，更新供后续使用 |
