# V2.3 找到可用数据，并进入研究流程

用户目标是可持续取得、可分析和筛选的数据，不能以历史表格展示代替实际使用。本轮增加无需Key的DefiLlama币安公开钱包储备数据，接入原型的辅助筛选、排序、详情、报告证据和策略观察草案。

## 两种口径分别处理

| 数据 | 当前情况 | 用途 |
|---|---|---|
| 原⑤带标签的交易所逐笔流入/流出 | Santiment近期免费权限受限，当前仍未知；有10资产历史样本 | 精确净流指标保留，不伪造 |
| ⑤扩展：币安局部储备数量变化 | DefiLlama公开接口已实测可用，18原生链资产、40合约关联 | 辅助筛选、持续减少观察、投研证据 |

来源：https://api.llama.fi/protocol/binance-cex 。来源方法及代码：[DefiLlama Binance Adapter](https://github.com/DefiLlama/DefiLlama-Adapters/blob/main/projects/binance/index.js)。覆盖币安PoR公开钱包及部分挂钩资产 backing 钱包，非币安所有钱包或稳定不变的地址集合。链上余额变化可能来自钱包集合变更、储备金/托管转移、供应商错误，不能直接确认净提币、买入或吸筹。

按币本位数量计算变化，忽略USD TVL的价格变动。只计算相邻完整UTC日快照；最新完整日截止2026-10-13 00:00 UTC，即北京时间10月13日08:00。当天03:25 UTC的最新部分日数据不用于完整日比较。

仅启用明确的原生币与原生网络映射，不将ERC20同名代码、包装币或跨链数量直接合并。18资产为BTC、DOGE、XRP、DOT、NEAR、SOL、TRX、BNB、AVAX、APT、SUI、XLM、ALGO、HBAR、CHZ、S、RONIN、CELO。LTC缺少连续有效数量，仍为未知；ETH的质押/多链归并和MAGIC、PUMP等代币地址映射不在本轮已核验覆盖中。

## 如何利用

市场集中筛选工作台新增“⑤扩展·储备辅助筛选”，支持：不限、有近期证据、日减少阈值、7日减少阈值、连续至少3日减少。它作为额外AND条件，可与原六指标及市值范围组合，但不计入6项命中；原⑤不会因此变为满足。缺失、超过36小时或异常数量不填0，进入待核验。

增加日/7日储备变化排序与合约证据摘要。合约行情仍是10月12日晚快照，储备是10月13日08:00，明确标记跨时点观察名单，不宣称同步交易信号。

“数据与任务→数据覆盖”展示近期资产、余额、日变化、7日变化、连续减少天数，支持直接带入唯一USDT合约投研。生成数据报告和AI请求预览均包含来源、独立日期、数据类型、范围及限制；尚未真实调用AI。

策略草案采取“储备减少→排除钱包/托管异常→等待同期价格修复/箱体突破→现货佐证”的流程。建议首先验证日减少1%、周减少3%、连续3天等候选阈值，均未验证收益。完整K线、同期合约记录、冻结规则、撮合账本仍未齐，草案不运行。

## 本次观察举例

- APT日变化−9.068%，7日却为+29.539%，不能只看单日就解释为持续供给收缩。
- NEAR日变化−1.854%，7日−1.700%，列为单日减少观察。
- TRX7日−3.657%，连续6日减少，列为持续储备减少观察；其旧合约快照未满足①②③，不直接给出开多信号。
- DOGE7日−3.854%，连续2日减少。

日减少≥1%有2资产、4合约关联；周减少≥3%有2资产、5合约关联；连续3日减少有1资产、2合约关联。548份合约无已核验近期储备证据；它们是未知，不是未减少。

## 更新与记录

`../cex_reserves.py` 实际访问公开接口、校验连续8个日余额、计算变化和保留来源。成功结果写入 `../cex-reserves.json` 并另存 `../reserve-history/`；原 `scan.json` 不覆盖。失败保留上次成功发布的数据，客户端超过36小时判为未知。

手动重新采集并发布原型：

```powershell
python -X utf8 cex_reserves.py
python -X utf8 design\integrate-reserves.py
```

从项目根运行；刷新原型即可读取。采集和计算不调用AI。正式调度应低频查询并以新增完整日记录为更新依据，可以挂到既有4小时程序任务，但本轮未创建自动任务或HTTP更新接口。原型更新通过真实脚本发布，不把演示按钮当作后台功能。
