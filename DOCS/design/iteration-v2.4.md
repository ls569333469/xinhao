## 发布与恢复

```powershell
python -X utf8 design\integrate-evidence.py
```

上述脚本读取本地存量证据，发布完整快照到原型并更新初版的辅助证据。共享渲染代码由原型静态加载、初版内嵌，不需要重启服务或扩大访问路径。若更新储备，先运行原有储备采集及integrate-reserves.py，再运行integrate-evidence.py发布到两页。备份为prototype-v2.3.html与index-before-evidence.html。

核验包括已有4,374组三态筛选案例和32组策略快照检查，以及浏览器六列状态、列选择、跨页选币、组合筛选、详情、排序、报告和CSV导出。AI后台、定时调度及模拟撮合仍未接入。
