## 使用

两个页面地址保持8767/8768。启动只读已有数据。下一次明确手动扫描运行`python -X utf8 scanner.py --scan`，成功后运行`python -X utf8 design\integrate-evidence.py`同步新版。

扫描锁在`scan.lock`。异常退出留下孤立锁时，先核实记录PID与实际进程，不能直接抢锁。新增归档在`scan-history`，不可将已有实验依赖历史当缓存清理。本轮没有启动真实扫描、AI、调度或交易。
