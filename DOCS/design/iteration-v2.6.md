# V2.6 · 扫描任务与持久更新计划

统一需求见[requirements.md](requirements.md)§9。本轮承接V2.5扫描发布契约，把网页的真实手动扫描、任务查询、扫描设置保存与周期调度接通。

## 已实现

- server.py同进程托管8767/8768；两个页面通过同源API访问同一SQLite任务服务。
- POST /api/scans、GET /api/tasks、GET /api/tasks/:id、POST /api/tasks/:id/cancel；并发手动/定时复用一个queued/running任务。仅排队可取消。
- GET/PUT /api/settings只接受扫描配置，版本冲突409；GET /api/health显示服务及调度能力，不假报上游可用。
- 首次默认关闭，支持1/4/8/24小时间隔；UTC经过时长调度。重启中断任务标失败、到期最多补一次、不积压；关闭计划不打断在途扫描。
- 顶部集中扫描/读取，数据与任务展示进度/状态/错误/scan_id及revision；更新页独立保存真实扫描设置；读取新快照重算候选，旧报告与预览失效。
- 明确静态白名单，严格Host和同源JSON写保护；runtime/源码/审计包不可GET或HEAD下载。没有保存AI密钥。
