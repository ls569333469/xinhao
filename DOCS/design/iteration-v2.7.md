# V2.7 · 区间行情补查与覆盖预检

本轮推进R1的区间价格证据能力。新增手动区间补查、独立归档和本地覆盖检查；没有启用自动任务、调用AI、运行模拟或生成收益。当前实际状态以[统一需求](requirements.md)§10为准。

## 使用入口

新版页面“数据与任务 → 区间行情补查”：查找并多选合约，或使用市场已选；选择4h/日线、UTC开始/结束时间；检查本地覆盖，再提交区间补查。“任务记录”可看排队、进度及错误；“区间归档”显示每份合约取得/应有、缺口和实际可得时间。

每任务1–20份当前快照内合约，最长366天；支持USDⓈ-M与COIN-M公开合约价格，不需要Key。这里只补价格K线，不能补出历史市值、OI、账户比、链上流或全市场ATH。无需高频AI请求。

## 数据与时间契约

- 区间为[start,end)，仅纳入完全包含于其中的UTC对齐已收盘K线。开始向上、结束向下对齐；不足一根拒绝，未来结束拒绝。页面明确UTC，避免与北京时间显示混用。
- 固定币安公开klines端点，不接受URL；每请求最多500根、最长200天，显式startTime/endTime分页，避免COIN-M按最近limit截断跳过旧K线。空页继续下一窗口，缺数据不补0。
- 检查12列结构、OHLC关系、有限值、非负量、open/close时间和请求边界。完全相同重复幂等；矛盾重复排除并记冲突。源错误/限流停止后续请求，不连续追打源。
- 每个任务生成新的candle-history/range-<id>目录，保留冻结请求、快照SHA256/版本、分页原始响应、合约原始序列、来源、retrieved_at/available_at和SHA256。最终manifest只创建一次；再次补查产生新目录，不覆写旧归档，也不改scan.json。
- available_at是实际补查/归档时间，不能当成历史K线当时已被系统取得。断档包括边界、内部和上市前无行情；当前不能自动区分这些原因，保守保留缺口。
- 本地预检仅合并区间补查归档，验证合约文件SHA256、按开盘时间去重；冲突保留unknown，损坏归档不计覆盖。旧扫描返回窗口尚未纳入此索引；覆盖100%也不意味着历史六指标或完整ATH可用。

## 任务与接口

SQLite增量迁移tasks.request/request_hash。扫描与补查共用单工作队列；同参数、同输入快照的在途补查复用，不同补查按顺序排队。相同时刻按入库顺序保持FIFO。网页/CLI共用ScanLease，锁存在不抢占。

扫描计划、配置版本和默认关闭状态保持；本轮没有行情自动补查计划。仅queued可取消。重启中断补查标failed，保留已写证据、不自动重跑；以后由账本按实验所需缺口调度。success为全部完整且无排除错误，partial_success为至少取得一根但仍有缺口/排除，failed为无可用数据或异常；失败归档仍可审计。

| 接口 | 用途 |
|---|---|
| POST /api/candles/preflight | 只读本地覆盖检查，不联网、不创建任务 |
| POST /api/candles/backfills | 冻结请求并排队，返回202与复用状态 |
| GET /api/candles/history | 最近50个完成归档的合约覆盖与源错误 |
| GET /api/tasks | 同时显示扫描和区间补查任务 |

新增写接口沿用同源Origin/Host、JSON与16KB请求上限；归档/源码/SQLite仍不开放静态下载。服务与启动器同步为2.7，两个页面共用服务。

## 验收与后续

离线模拟源覆盖分页/边界、空页/缺口、异常K线/重复冲突、限流、共享锁、归档不变与快照不变、覆盖合并与损坏校验、并发去重、混合串行队列、SQLite迁移/取消/重启、HTTP同源保护。验收结果和浏览器截图见design/v27-validation.json及design/v27-range-check.png。

R1仍缺全生命周期价格/可信ATH来源、逐字段覆盖、扫描窗口统一索引和快照revision浏览。下一步R2需要持久账户/策略参数、白名单触发/退出与冻结版本，再接区间撮合/资金结算/追加账本；R3凭证与AI、R4结构策略及历史收益仍待开发。不能把本轮补查工具当成已完成回测。

最终验收：57项Python测试（新增19项），4,374组筛选、588合约×6指标×8策略跨端一致性及75字段CSV通过；62个维护Markdown本地链接通过。浏览器模拟源完整6/6为成功、故意缺口5/6为部分成功；两页无warn/error。正式服务2.7，扫描计划仍v3/关闭/4h，真实任务和补查归档均0；五份原行情/审计文件SHA256不变。浏览器证明只用模拟源，未验证当前上游网络可达性。
