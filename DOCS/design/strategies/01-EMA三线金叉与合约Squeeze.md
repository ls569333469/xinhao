## 一、核心逻辑：火药桶 + 点火器

**火药桶（合约结构）+ 点火器（EMA 金叉 + 量能）= Short Squeeze 引爆**

空头过度拥挤 → 价格上涨 → 空头被迫止损 → 推动价格继续涨 → 更多空头止损 → 滚雪球效应。

- **火药桶**：OI/流通市值高、账户数多空比低（空头账户多）、负费率加分 → 结构上有挤空燃料。
- **点火器**：4H 上 EMA7/25/99 形成金叉（或多头排列），且当根量能够猛 → 才谈入场。
- **只筛不买**：第一阶段只进观察名单；没有点火器，再漂亮的结构也不入场。

## 二、第一阶段：筛选候选池（不入场）

以下条件凑齐才进观察名单。③ 是加分项；①②④ 是硬门槛（实务上可把③当强化分，但 Prompt 扫描时建议仍一并看）。

### ① OI / 流通市值 > 30%

- 含义：合约杠杆密度高，强平规模大。
- **> 50%**：高度警戒。
- 算法：`合约未平仓量（美元）÷ 流通市值（美元）`。

### ② 账户数多空比 < 0.80

- 含义：空头账户数量远多于多头，Squeeze 燃料更足。
- **必须看「账户数比」，不要看「持仓量比」**（持仓量比容易被大户单子扭曲）。

### ③ 资金费率年化 < −50%（加分项）

- 含义：空头每天在付钱，拖越久越难撑。
- 年化近似：`单次费率 × 3 × 365`（按 8h 结算习惯；若结算周期不是 8h，要按真实周期换算，别硬套）。
- **−150% 以上**：接近临界，更值得盯。

### ④ 价格在 EMA7 / EMA25 / EMA99 三线全部下方横盘

- 含义：还没启动，在蓄力区。
- **横盘震荡**（可观察）：RSI 约 30–55，近 7 天没有持续创新低。
- **趋势性死亡下跌**（直接排除）：一路持续创新低，不是「三线下方就可以捡」。

## 三、第二阶段：入场信号分级

### 🟢 强信号（最可靠）

同时满足：

1. `EMA7 > EMA25 > EMA99`（完全多头排列）
2. 当根 K 线成交量 **≥ 前 7 根均量的 2 倍**

案例印象：ZEREBRO（金叉量能约 6×，峰值约 +51%）、WAL（金叉量能约 60×，峰值约 +59%）。

### 🟡 中信号（要量能配合）

同时满足：

1. EMA7 上穿 EMA25
2. 价格站上 EMA99
3. 量能 ≥ 2×  
4. 此时 EMA25 往往还在 EMA99 下方 → 金叉尚未完全确立，可靠性弱于强信号

### 🔴 弱信号（尽量避开）

- 价格站上 EMA99，但 EMA7 / EMA25 **仍是死叉排列**。
- 案例：NIL 第一次突破——价冲上去、均线还死叉，随后很容易打回去。

## 四、EMA 技术说明（别算错）

| 参数 | 说明 |
|------|------|
| 指标类型 | **EMA**（指数移动平均），**不是** SMA |
| 周期 | EMA7 / EMA25 / EMA99 |
| K 线周期 | **4H** |
| 数据源 | **统一用合约 K 线**，跟 OI / 多空比同一套市场口径 |
| 金叉定义（本手册「完全金叉」） | 当前：`EMA7 > EMA25 > EMA99`；且**上一根**还不满足这套排列（刚形成） |
| 量能 | `金叉当根成交量 ÷ 前 7 根均量`；实务上也可看「当根或紧接下一根」是否 ≥ 2× |
| EMA 计算窗口 | **必须用完整历史 K 线**滚出来；短窗口硬算会让 EMA99 严重失真 |

## 五、完整操作流程（Step 1–6）

**Step 1【筛选】**  
每 4 小时扫一遍合约市场。条件：`OI/MCap > 30%` + 账户数多空比 `< 0.80` + 价格在三线下方横盘 + RSI 约 30–55 → **只进观察名单，不入场**。

**Step 2【验证横盘】**  
确认近 7 天没有持续创新低；OI 在高位维持、没有明显萎缩。

**Step 3【等待金叉】**  
盯 4H。等 EMA7 上穿 EMA25，且最终形成 / 走向 `EMA7 > EMA25 > EMA99`（强信号要完全多头排列）。

**Step 4【确认量能】**  
金叉当根，或紧接下一根：成交量 ≥ 前 7 根均量的 **2 倍**。

**Step 5【入场】**  
Step 3 + Step 4 同时满足 → 才考虑做多（优先 🟢，其次 🟡）。

**Step 6【止损】**  
以 EMA99 作参考止损带；**跌破 EMA99 清仓**（具体下单价位自己按滑点/结构微调，手册只定原则）。

## 六、避坑清单（假突破过滤）

- 多空比只信**账户数比**，别拿持仓量比凑数。
- 价格连续创新低 = 趋势性死亡 → **直接排除**，别当「三线下方蓄力」。
- **没放量的金叉**可靠性极低（DUSK 多次金叉但量能不足，要警惕）。
- OI/MCap 很高但多空比 `> 1.0`（空头并不拥挤）= 有火药没燃料，如 AKE。
- 金叉后价格已经暴拉（例如 **> 40%**）→ 先别追；等回调到 EMA7 附近再评估。
- 弱信号（价上 EMA99、双线仍死叉）优先当反面教材，不当入场理由。
- 费率年化换算要和真实结算周期对齐；别默认所有币都是 8h。

### D.3 强级两种路径：拆开变更，不捆绑新增条件

设 t 为当前闭合4H根，E7/E25/E99为对应根EMA。待比较的两种触发路径为：

```text
共同结构：E7[t] > E25[t] > E99[t]

路径A：共同结构成立，且 E25[t-1] <= E99[t-1]
路径B：共同结构成立，且 E7[t-1] <= E25[t-1]
       且 E25[t-1] > E99[t-1]
```

路径B用于识别EMA25此前已在EMA99上方、随后EMA7上穿EMA25形成完整排列的事件。以此前EMA25位置分支，可避免同一根同时算A/B；同根多条均线交叉不能只凭“先后两步”的叙述推断过程。若未来采用B且与中级同时满足，应强级优先、保留路径证据，不制造两次策略提醒。

币安 AI 附加的 `收盘[t] > E7[t]` 是另一项价格过滤：会排除完整多头排列中回踩EMA7的情况。它并非补齐路径B所必需，须独立比较，不在本附录默认加入。

仅记录既有完整排列，不等于新金叉事件；重扫、重启、价格回踩均不能无条件生成新事件。A/B路径的收益、假突破和风险差异尚未验证。

### D.4 弱级：新穿、持续根数与历史证据
