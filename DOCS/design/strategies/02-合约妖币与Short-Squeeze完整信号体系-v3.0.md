# **一、体系总览与核心逻辑**

本方案整合两套独立策略，共用筛选层，在第二层分叉执行：

**① Short Squeeze 策略** 利用合约结构性失衡（高OI + 空头拥挤），等待技术信号触发，参与空头被迫回补引发的强制上涨。

**② 妖币操盘策略** 识别庄家主动操控合约价格的两种模式（长周期控盘 / 快速拉高出货），在不同阶段使用不同信号入场。

**核心逻辑公式：**

> *火药（合约结构）+ 点火器（技术信号）+ 庄家未出货（LSR确认）= 高胜率入场机会*
> 

三者缺一，胜率大幅下降。这是所有规则的根本依据。

# **二、指标体系详解（10个可用指标）**

### **指标① OI / 流通市值比**

**定义：** 合约未平仓量（美元）÷ 代币流通市值（美元）× 100%

**逻辑：** 衡量杠杆密度。当OI接近甚至超过流通市值时，一旦触发空头止损，连锁反应规模与流通市值相当——价格上涨 → 空头止损 → 更多买单 → 价格继续涨 → 更多空头止损，形成核聚变效应。

**阈值：**

- > 30%：关注，火药存在，有引爆潜力
- > 50%：高度警戒，引爆后涨幅往往更大
- > 100%：极端情况（龙虾曾达此量级），定价权几乎完全在合约

**实测有效性：** 高OI组（>30%）平均72h涨幅+17.4%，低OI组（<15%）仅 +5.4%，相差3倍。

**使用方式：** 必要条件之一，不单独使用。

**数据获取：**

`binance-pro-cli workflow arb-scan --symbols A,B,C --format json
返回字段：open_interest_usd`

### **指标② 账户数多空比（LSR）—— 全体系最核心指标**

**定义：** 做多账户数 ÷ 做空账户数（必须用账户数比，不用持仓量比）

**逻辑有两层：**

第一层（入场前）：LSR < 0.80 表示空头账户数量远多于多头。在 Squeeze 策略中意味着大量空头需被迫回补；在妖币策略中意味着庄家自己持多头仓位、尚未出货。

第二层（持仓中）：LSR 的走势方向比数值本身更重要。拉升后 LSR 急升至 2.0+ = 散户大量追多接盘，庄家开始出货；LSR 不升 = 庄家仍控盘，每次回调都是再次入场机会。

**为什么用账户数比：** 持仓量比容易被单笔鲸鱼大单扭曲，账户数比反映真实参与人数方向偏向，更难被操控。

**阈值细则：**

| **LSR值** | **含义** | **操作** |
| --- | --- | --- |
| < 0.65 | 极端空头拥挤，Squeeze燃料极充足 | 优先入池 |
| 0.65 ~ 0.80 | 空头拥挤 | 入池 |
| 0.80 ~ 1.20 | 中性 | 不入池 |
| 1.20 ~ 2.00 | 多头偏多，散户开始接棒 | 减仓观察 |
| > 2.00 | 多头拥挤，庄家出货信号 | 离场准备 |
| > 4.00 | 极端多头拥挤，已完全派发 | 坚决不碰 |

**实测：** 空头拥挤组（LSR<0.80）平均72h涨+13.3%，多头拥挤组（LSR>1.20）仅+7.0%。

### 指标③ 资金费率（辅助时序指标）

**定义：** 合约资金费率年化值 = 单次费率 × 3 × 365

**重要修正：实测单独无效。** 极度负费率组（WAL -494%、MAGIC -187%）后续72h实际没有上涨，正费率组反而有涨幅。命中率 0%，平均涨幅 -0.7%。

**正确用法（时序辅助，不作入场条件）：**
- 持续负值 = 空头在付钱，承压积累，但不意味着即将引爆
- 从负值转为正值 = 拉升已经开始的确认信号（不是入场点）
- 拉升后大幅正值（> +20% 年化）= 散户深度追多，庄家出货，**离场预警**

**使用规则：**
- 一级减仓：费率从负转正 + LSR开始上升 → 减半仓
- 二级离场：费率年化 > +20% + LSR > 2.0 → 全出

### 指标④ EMA三线金叉（入场触发信号）

**定义：** 使用合约4H K线的 EMA7 / EMA25 / EMA99（必须用EMA不用SMA，必须用合约K线不用现货K线）

**金叉精确定义（双重条件）：**
- 当前4H收盘：EMA7 > EMA25 > EMA99 且 价格 > EMA7（完全多头排列）
- 上一根4H收盘：EMA25 ≤ EMA99（首次成立，非持续金叉）

这个双重条件确保只在完全金叉**首次成立**时触发，避免已持续金叉状态重复产生信号。**废弃的旧定义：**「价格在三线下方」—— 实测命中率 0%，涨幅仅 +5.6%。三线下方是**入池候选状态**，不是入场信号。

**实测有效性：** EMA金叉 + 量能≥2x 组合命中率 100%，平均涨幅 +84.8%。

**数据获取：**`

binance-cli futures-usds kline-candlestick-data --symbol BTWUSDT --interval 4h --limit 300 取 index4（收盘价）序列自行计算EMA

`**EMA标准计算代码：**
```python
def ema_full(prices, n):
    k = 2/(n+1)
    e = sum(prices[:n]) / n
    for p in prices[n:]:
        e = p*k + e*(1-k)
    return e
# 必须传入完整历史序列（≥300根），否则EMA99虚低产生假信号`

### **指标⑤ 量能放大（入场确认）**

**定义：** 金叉当根K线成交量 ÷ 前7根均量

**逻辑：** EMA金叉是趋势信号，无量能配合说明只是技术浮动，不是真实资金涌入。量能放大才证明有真实买盘支撑突破。

**使用规则：**

- 金叉当根量能 ≥ 2x → 直接确认，下一根开盘买入
- 不足 → 等下一根，量能 ≥ 2x → 确认
- 两根均不足 → 信号作废，等下次金叉（**最多延迟1根**）

**特殊情况（长周期控盘型）：** BTW/RIVER 历史金叉时量能普遍只有 0.4-1.5x，低量反而是真信号。判断是否放宽：LSR < 0.65 且历史有多轮低量拉升 → 门槛放宽至 ≥ 1x。

**数据获取：**

```
K线数据 index7 = quote volume（计价量，用于计算量能倍数）
```

**定义：** 1H K线某根成交量 > 7日均量8倍以上，且同根价格变化 < 3%

**逻辑：** 大量成交但价格几乎不动，说明有大资金悄悄吃单但故意压住价格——庄家建仓尾声、即将点火的典型特征。比实际启动早 **8-20小时**出现。

**关键约束（实测重要发现）：**

- 仅在 EMA金叉上方 或 EMA7>EMA25 混合位置有效

**使用流程：**

- 背离出现 → 下一根1H量能维持 > 2x → 跟进
- 下一根量能回落 < 2x → 信号失效，不追

**实测有效性：** 有背离组平均 +37.3% 命中率67%；无背离组平均 -0.6% 命中率0%。**12个指标中单独有效性最强。**

**定义：** RSI(14) 4H周期 < 25

**逻辑：** 高频操盘型妖币（龙虾/RAVE/BEAT）的庄家节奏是：低位横盘吸筹（RSI极低）→ 突然爆发。RSI超卖不是看空信号，而是庄家蓄力完毕准备启动的前兆。越超卖越接近爆发点。**关键前提（不可省略）：LSR < 1.5。** BEAT 2026-08-19 RSI=8 但 LSR=2.92（已派发），后续10天 +0%。**RSI超卖 + LSR高位 = 死猫反弹，不是真实启动。**

- RSI < 25：基础触发，进入观察
- RSI < 15：强力触发，龙虾/RAVE历史命中率最高区间

**组合使用：** RSI<25 + 三线下方 + LSR<1.5 = C型候选状态。等量能突然 > 3x 那根4H收盘 = 真正入场时机。

### **指标⑨ OI背离价格新高（离场预警）**

**定义：** 价格创新高，但同期OI不增反降

**逻辑：** 正常上涨OI会随价格新高增加（新多头入场）。OI不跟随说明上涨靠空头被平仓推动，新资金未进场，驱动力即将耗尽。**比 LSR>2.0 更早出现（通常提前1-2根4H K线）。**

**使用：** 持仓中价格创本轮新高时，检查当前OI vs 前高时OI。当前OI

< 前高时OI → 减仓准备。

---

### **指标⑩ Vol/OI比（操盘痕迹识别）**

**定义：** 日成交量 ÷ 当前OI

正常代币日成交量约为OI的1-3倍。Vol/OI > 10x = 同一筹码被反复倒手，庄家自买自卖推高成交量的痕迹。

**双向使用（看变化方向，不看绝对值）：**

- Vol/OI 突然升至 > 10x → 庄家推价加速，可持仓
- Vol/OI 从高位（>5x）回落至 < 1x → 庄家停止推价，减仓信号

目标：从全市场500+个合约中筛出值得持续监控的标的。入池是一次性判断，入池后不因下次扫描删除。

### **入池必要条件（同时满足）**

**条件①：OI / 流通市值 > 30%**

**条件②：账户数多空比（LSR）< 0.80**

**条件③：价格结构满足以下全部：**

`价格在合约4H EMA7 / EMA25 / EMA99 全部下方（蓄力位，未启动）
RSI(14) 在 25~60 之间（非超卖死跌，非过热追高）
过去14根4H K线内，不超过2根收盘价创新低（横盘不是下跌）
过去20根4H K线，最高价 / 最低价 < 1.35（波动幅度<35%）`

**加分项（不必须，但提高优先级）：**

`⑥ 过去30根4H K线内出现量价背离
  （成交量 > 3x日均量 且 同根价格变化 < 3%）
③ 资金费率年化 < -50%
  （空头在承压，时间站在多头一边）`

### **候选池管理规则**

**入池：** 记录当时OI值作为基准

**保留：** 已入池标的不删除，状态持续流转

**出池条件（满足任一即出池）：**

`1. OI < 入池时OI × 70%（萎缩超30%，火药散了）
2. 入池后超过30天未形成完全金叉
   起算时间是入池时间，不是金叉时间
3. 止损触发（4H收盘跌破EMA99追踪止损线）`

**状态流转（单向，不回退）：**

`【蓄力期】价格在三线下方横盘
    ↓ EMA7上穿EMA25（4H收盘确认）
【中信号】EMA7 > EMA25，EMA25仍在EMA99下方
    ↓ EMA25上穿EMA99（4H收盘确认）
【完全金叉】EMA7>EMA25>EMA99首次成立 ← 触发入场检查
    ↓ 跌破EMA99（4H收盘确认）
【出池 / 止损】`

    if len(prices) < n: return None

    for p in prices[n:]:
        e = p*k + e*(1-k)
    return e

### 3.1 B：不能在确认时把估算的下一根开盘当作已知事实
