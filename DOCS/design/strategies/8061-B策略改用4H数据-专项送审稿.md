# 策略B“庄家吸筹背离”改用4H数据：专项送审稿

日期：2026-10-16  
状态：**周期变更可行性讨论稿，尚未选择最终阈值，未更新代码。**  
关联：[统一更新方案v3.1 r1](8062-合约妖币与Short-Squeeze-统一更新方案-v3.1-送审稿.md)。A与C、当前六项指标维持原方案；本稿仅讨论B由1H改为4H。  
审核目标：请回答**B的信号计算周期改成4H是否适合**，并给出4H研究版本。不是讨论“保留1H信号、每4小时扫描”的调度替代方案。

## 一、为什么考虑统一4H

我们已有“异动观察工作台”，统一采集合约4H K线（最多1500根）、日线、OI、账户多空比、资金费率与可信市值。

现有4H数据已用于EMA三线金叉、RSI、横盘、新低、量能，以及将6根4H组成24h窗的I6。合约身份、时间、单位、质量和归档有基础能力。

如果B也用4H：
- 可以直接复用同一份已收盘4H原始数据，不为B重复拉相同K线；
- 可在现有扫描中统一计算、归档与展示；
- 不必为了B的信号周期先新增1H采集或小时专项任务；
- 仍须增加B自己的候选、事件、确认、失效、统计与展示，不能认为只改interval即可完成；
- OI/账户比的同期证据仍需单独处理，统一K线不自动解决所有数据缺口。

用户偏好“庄家吸筹、控盘、出货预警、点火”等通俗名称，展示继续保留；公式和证据放详情。请勿把审核重点转成改写全部展示词。

## 二、1H原研究基线与4H待确定项

| 项目 | 1H原研究基线 | 改4H后需审核 |
|---|---|---|
| 背景 | 事件时最近已闭合4H EMA7>EMA25 | 背景同样是4H；明确采用事件根本身闭合后的EMA |
| 结构资格 | OI/市值>30%、LSR<0.80 | 可保持研究基线，是否调整须给依据 |
| 量基准 | 前168根1H，即7天 | 若保持7天，应为前42根4H；不能原样168 |
| 放量 | 当根成交额/基准均值≥8 | 8倍不能无证据照搬，需4H阈值 |
| 价变 | abs(C/O-1)<3% | 时间变长后3%是否适合；振幅/影线是否另设观察 |
| 确认 | h+1小时量比≥2及背景/结构保持 | 改成再等4h是否太晚？是否采用当根确认 |
| 最早参考 | 确认后的下一根1H开盘 | 确认后的下一根4H开盘 |
| 风险线 | 确认时最新闭合4H EMA99 | 可沿用研究变体，但需验证周期变化后的效果 |
| 参考价资格 | P>S0；未知不成交，P≤S0不生成该变体模拟成交 | 继续明确，不因4H更平滑而取消 |
| 运行 | 1H监测或较晚发现 | 4H信号可随现有扫描；扫描是否贴近收盘仍需核对 |

1H版本尚未验证有效，4H也不应称为已经保留同等胜率。选择4H的工程收益与策略收益分开评估。

## 三、改成4H可能出现的问题

### P1：小时吸筹被合并稀释，可能漏掉原1H信号

假设正常每小时成交额为V，某小时放量8V、另外3小时各V：
- 该1H量比为8；
- 合并4H成交额为11V；
- 正常4H均量约4V；
- 4H量比约2.75，而不是8。

这是解释聚合稀释的简化例子，假设历史各小时均量稳定，不是4H阈值建议。

**请审核：**
- 4H应识别“持续蓄力”，还是也要捕捉一小时脉冲？
- 若一小时脉冲是主要优势，4H可能损失多少识别能力？请用可核验样例说明，不虚构总体命中率。
- 4H的放量阈值应如何提出并验证？

只有4H OHLCV无法还原4个小时的成交量分布，不能在没有1H数据时宣称某4H信号与1H完全等价。

### P2：四小时涨跌互相抵消，容易把出货误认成吸筹

4H开盘1.00、最高1.30、最低0.95、收盘1.01：
- C/O变化仅1%，满足“小价变”；
- 但整根振幅很大，可能经历拉高后回落；
- 高成交额加小实体不能直接证明吸筹。

4H的高低价和影线可显示这种风险，但不能确定内部涨跌顺序、资金身份或完整买卖路径。

**请审核：**
- 是否记录/过滤振幅=(H-L)/O？
- 是否记录收盘在全根位置=(C-L)/(H-L)，以及上下影比例？
- 当H=L或实体为0时如何处理分母？
- 这些只作观察，还是哪个应成为4H研究确认条件？请分开说明。

不因“阳线”就认定净买入；C/O、振幅和主动买卖量差是不同证据。

### P3：7根、42根、168根不是同一种量能基准

| 4H基准长度 | 覆盖时长 | 可能影响 |
|---|---|---|
| 前7根 | 28小时 | 适应快，可能被短期异动抬高或低量期压低 |
| 前42根 | 7天 | 保留原1H版的7天时间跨度，但分布已改变 |
| 前168根 | 28天 | 更慢，可能受上市初期、旧行情和长期活跃度变化影响 |

所有分母均不含当根，缺完整连续基准时未知，不拿较少根数仍除固定N。

**请审核：**优先建议一个主基准，给依据；若需对照，最多再给一个必要变体，不把所有窗口与阈值组合一起上线。保持7天时间跨度只使前42根成为自然候选，不证明它最优。

### P4：4H成交量分布不同，不能简单沿用或等比例缩放阈值

“8倍÷4=2倍”不是普遍成立的转换。不同小时活跃度、日内节奏、极端值及持续放量都会改变合并后的分布。

同理，价变<3%、下一根量比≥2也不能无验证照搬。

**请提供：**
- 当根放量阈值、价变阈值与确认量阈值的初始研究建议；
- 边界采用>还是≥；
- 选择理由；
- 哪些只是经验假设；
- 如何记录被筛掉的样本，避免只挑成功案例。

### P5：等待下一根确认会再增加4小时

设事件根T为00:00～04:00 UTC：
- 当根收盘确认：最早参考04:00的T+1开盘；
- 等T+1（04:00～08:00）收盘确认：最早参考08:00的T+2开盘。

不能在08:00才确认，却回填04:00开盘成交。扫描运行和接口延迟还会增加实际发现延迟，不承诺“4H扫描天然就是收盘即时执行”。

**请比较两种独立研究方式：**
1. 当根达到完整条件就确认；
2. 当根只标吸筹，紧接下一根再确认。

若提出“高质量当根确认、普通事件等下一根”的混合规则，必须给出互斥条件、优先级和稳定事件身份，不临时按案例选择。

需要说明是否会因等待确认错过启动，以及当根确认是否增加出货误判。没有对照证据时直接标待验证。

### P6：事件背景与事件本身同周期，不能混用旧EMA和当前EMA

改为4H后，T事件收盘时：
- 可以计算并使用T本身已闭合后的EMA7/25/99；
- 若采用上一根T-1背景，是另一研究定义，必须写清；
- 不能一处用T-1，一处默认用T。

若T+1才确认，复核T+1闭合后的背景，固定止损锚点也须明确是T还是T+1。

**建议送审口径：**T触发用T已闭合EMA，T+1确认用T+1已闭合EMA；背景只要求EMA7>EMA25，完整多头排列或价格>EMA99另作变体。请审核合理性。

B与A候选分开：不因数据共用，就强制B也先满足A的RSI30～55和三线下方。

### P7：统一4H不会自动取得信号当时的OI/LSR

当前扫描会取得扫描时最新OI和近期账户比。比如06:00扫描04:00收盘的事件，06:00值不能自动充当04:00值。

**请审核：**
- 4H B是否继续要求事件与确认收盘时的OI/市值、LSR资格？
- 若继续要求，需历史采集/收盘采样；无法取得时完整资格未知，技术事件可以保留。
- 是否同意沿v3.1 r1，以收盘边界为基准检查5分钟内、不晚于该时点的有效样本，并把5分钟标为研究参数？
- 延迟发现另存当前值，不重写事件时资格。

改4H只能减少对1H行情与小时任务的需求，不能拿“已有OI字段”当作历史同期数据已齐备。

### P8：4H吸筹可能与I6、A量能形成重复标签和重复计分

- I6是24h成交额与前7个独立24h窗比较，另要求同窗价变<2%。
- A量能是当根4H与前7根4H比较，用来确认交叉事件。
- 新B4H将是独立4H量增价平及背景条件。

它们可同时命中，但不是三份独立资金证据。

**建议：**
- 保持I6、A点火量比、B4H字段与策略ID独立；
- 名称分别显示“24h量增价平”“EMA点火放量”“4H庄家吸筹背离”；
- 同币同根关联同一行情，单列哪些策略满足，不重复加总收益、资金金额或自动叠仓；
- 不用B4H替换旧T4/T8或I6。

请说明B4H相较现有I6与A点火新增了什么实际筛选价值。

### P9：跨4H边界的吸筹可能被拆开

同一吸筹过程若发生在03:00～05:00 UTC，会分进相邻两根4H，单根量比可能都不达门槛。

**请审核：**
- 先接受固定交易所4H边界作为首版限制，是否合理？
- 是否有必要研究两根累计量？若有，如何避免与单根信号重复？
- 不得用滚动四小时窗口冒充标准4H K线；若研究滚动窗需要更细数据，工程复用优势会改变。

首版优先保持交易所标准4H，不在没有更细数据时虚构小时分布。

### P10：低基数、新上市与缺口可能制造高量比

极低历史成交额可能让普通成交显示极高倍数。新上市、停牌恢复、异常数据、缺K线也会影响均值。

**建议：**
- 分母≤0、缺根/无效成交额均为未知；
- 全部使用相同成交额单位，不拿代币数量跨资产比较；
- 同时记录当根绝对成交额、基准成交额、数据根数和上市历史；
- 是否另加绝对流动性门槛属于研究选择，请给理由，不能为了凑信号降低质量要求。

共用EMA背景仍需当前120根连续4H质量；即使B量窗只需42根，也不能据此认为EMA已经有效。

### P11：EMA99止损仍可能不适合4H吸筹信号

若B仅要求EMA7>EMA25，参考入场P可能≤止损S，仍须保留：
- P未知：风险资格未知，不成交；
- P≤S：保留技术事件，但该EMA99变体不生成研究入场；
- P>S：才进入该变体模拟资格，并记录距离；
- 不能把距离EMA当最大亏损。

4H当根/下一根确认会改变入场时点和EMA99锚点：
- 当根确认模式：S取T闭合EMA99；
- 下一根确认模式：S取T+1闭合EMA99；
- 后续仍按入场后闭合4H先判旧止损、首次盈利后只升不降、新线下根生效；
- 价格止损不依赖聪明钱或LSR补齐。

**请审核：**EMA99是否适合作为4H B主研究退出？若建议事件根低点或EMA25，请给独立完整变体，说明触发/成交时刻，不混入现行A规则。

### P12：研究统计必须按4H重新建样本

不能将原1H案例直接贴上4H标签，也不能只展示转换后仍成功的币。

验证应区分：
- 1H事件被4H保留、漏掉或新增误判；
- 发现与确认时间差；
- 当根确认与下一根确认；
- 技术事件、结构资格、风险资格、模拟成交；
- 固定时点收益、最大有利/不利波动、退出净收益和成本。

如果为了比较“1H转4H损失多少”，短期研究需要同一段真实1H与4H数据；这可以是一次性对照采样，不等于必须永久运行全市场1H任务。只研究4H本身时，可以不新增长期1H采集，但不能给出没有数据支持的等价性结论。

历史OI/LSR/市值缺失时，只能验证量价与技术部分；完整策略资格继续未知。已撤回的100%胜率和+84.8%不作为效果基准。

## 四、请币安AI给出的4H研究规则表

请填一个优先推荐的主研究版本；必要时最多一个确认方式变体。无依据的数值标“初始研究参数”，不要声称实测最优。

| 字段 | 请明确 |
|---|---|
| 策略名称/周期 | 4H庄家吸筹背离，独立于1H原版 |
| 量均值基准 | N根4H、覆盖时长、分母不含当根 |
| 放量阈值 | >或≥及数值 |
| 小价变 | C/O公式、阈值、边界 |
| 吸筹/出货形态 | 振幅、收盘位置、影线哪些观察、哪些硬条件 |
| 背景 | T已闭合EMA还是T-1；确认时怎样复核 |
| OI/LSR资格 | 阈值、事件/确认时点、未知如何处理 |
| 确认方式 | 当根/紧接下一根/明确互斥混合，不能含糊 |
| 确认量能基准 | 固定T基准还是T+1滚动基准 |
| 最早参考入场 | T+1或T+2真实开盘，扫描晚时怎样记录 |
| 等待/失效 | 只等几根、结构破坏/缺证据/到期 |
| 风险资格 | P>S、P未知与不合格的处理 |
| 止损/退出 | 锚点、更新顺序、收盘/盘中、次开成交 |
| 重复事件 | 同根重扫、连续多根吸筹、确认根又成新事件 |
| 展示与统计 | 吸筹/点火/延迟发现/未知，策略去重 |
| 工程增量 | 可复用4H部分与仍需新增的数据/状态 |

如果采用下一根确认：T+1本身又满足一个新吸筹事件时，要先处理旧事件确认，再按稳定规则保留新的独立事件，不能因分支提前返回漏掉；同一行情的多事件在统计时关联去重。

## 五、我们希望得到的明确结论

请按“接受 / 建议修改 / 待验证”回复，并直接回答：

1. 4H版是否值得作为我们现阶段B的优先实现？最主要的收益与损失是什么？
2. 哪些1H优势用4H必然不能还原，哪些只是需要重新设阈值？
3. 推荐的4H主研究规则是什么？请填写上表，不只返回扫描调度方案。
4. 有无与现有A/I6重复到缺乏新增价值的部分？
5. 为工程复用选择4H后，还有哪些数据必须补齐？
6. 哪些结论没有实际样本支持，应该怎样做最小对照验证？

我们的偏好是尽量复用现有4H扫描；如你认为1H无法替代，请说明策略原因。暂不承诺新增1H定时任务，也不因本稿改动A/C或执行真实交易。
