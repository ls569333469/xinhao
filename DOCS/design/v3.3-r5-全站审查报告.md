## 4. 必须处理的问题清单

P1表示阻断日常操作、可能误判或明显能力缺失；P2表示布局、文案和可读性问题。下列历史遗留也属于本次整体交付需要处理的范围，但不冒称全由顶部导航迁移新引入。

### P1-01 新旧指标入口和目录未统一

用户筛选截图只有旧六项；本轮统一入口有13项，指标库则仍使用旧目录，B/C等未登记。`design/unified-workbench.js:3–25` 与 `design/prototype.html:37` 分属不同目录/视图，状态说明未统一。应建立同一份信号目录、周期、实现状态和规则版本，保留旧注册表用于历史回放；禁止用旧目录覆盖新信号。用户截图具体旧入口加载原因待定位。

### P1-02 C与新增辅助只有入口，不能计作已完成

统一页明确“C及新增辅助未接入”。需要按v3.2及后续设计逐项区分“仅设计/入口”“源码实现”“离线通过”“现网运行验收”。本轮不将缺失值伪装成未命中，不以界面有卡片宣称信号已建成。

### P1-03 首页缺少开始扫描按钮

统一工作台只显示“读取本地最新”，原扫描控件随着旧区域被隐藏，而其他页面反而仍有“开始全市场扫描”。属于迁移遗漏。需在统一页恢复原任务入口、运行进度与1H/4H用途说明，保持共享队列；不得点击即同时启动两种独立扫描。项目外草稿已覆盖按钮恢复，现网尚未修复。

### P1-04 表格可选列显著退化

新界面提供10项原值列，旧23列能力中12个独立列入口缺失：24h成交额、标记价、指数价、EMA7、EMA25、EMA99、4H收盘价、资产OI、储备日变化、储备周变化、连续下降、历史净流。部分基础列仍保留，因此不能机械用23减10认定删13列。应恢复完整可选列和一键恢复默认/全部，数值缺失保留原因，不只放原始JSON。草稿已恢复列能力，未发布。

### P1-05 CSV从106个平铺字段退化为20列加raw JSON

数据并非因此全部消失，但Excel筛选和直接分析能力确实回退。应保留旧106字段兼容并追加新字段。项目外草稿124列已与旧导出进行588×106=62,328个单元格对照，差异0；该证据只适用于草稿，现网导出仍需修复。

### P1-06 旧组合按钮没有作用于新筛选

在模拟篮子点击EMA推荐的“按此组合筛选”，返回统一页仍未选信号，588/588。`design/prototype.html:189` 的 `applyCombination` 只更新旧DOM，`:231` 跨页按钮仍调用旧函数。需要统一组合适配和明确旧组合映射，保留当前EMA分级口径。证据：[组合返回截图](browser/basket-to-ema-filter.jpg)。草稿尚未覆盖这条跨页修复。

### P1-07 已选合约托盘不同步

统一页选择BTCUSDT并带入投研后，报告币池1份，但固定旧托盘仍“已选0”，按钮禁用。新旧页面共用Set但没有统一通知渲染；定位 `design/prototype.html:1140`、`:1329` 和 `design/unified-workbench.js` 选币/渲染路径。应让选币、托盘、投研范围与导出都由同一状态触发。证据：[托盘不一致](browser/selected-tray-mismatch.jpg)、[投研DOM](browser/selected-to-report.txt)。草稿尚未覆盖。

### P1-08 EMA确认筛选未充分排除失效事件

生产UI适配对crossConfirm过于宽松，没有充分核对cycle/void/blocked/duplicate，可能把不应参与当前确认筛选的记录带入。应区分原始技术交叉、有效确认事件、候选池状态；不改变A原判定算法。草稿已加入有效性过滤并有离线验证，现网尚未修复。

### P1-09 储备筛选从规则退化为“有覆盖”

原日/周/连续下降等条件未完整映射到新界面，存在有数据就当满足观察的语义退化。应恢复真实条件和未知态，不能把覆盖等价于命中。草稿已覆盖条件适配，现网未修复。

### P1-10 B原独立页面能力未完整迁移

旧B页被重定向到统一页，但原报告/CSV、轮次信息和可读逐事件明细未完整迁入。后端API和归档仍在，不能说数据已删除；用户访问能力确实退化。草稿已补报告/CSV与逐revision事件入口，仍待真实页面验收。清理功能应放数据管理，不混入信号筛选。

### P1-11 旧演示状态与真实运行数据并列，易误读

模拟篮子顶部盈亏/人数空态，与下方已有1持仓/3事件不同步；验证页旧“请先创建策略版本”与真实6冻结版本并存，“尚未启用定时”与真实review plan不一致，旧成绩空态与9条结算记录并列。属于既有双数据源/旧原型残留。应删除或隔离演示展示，保留真实记录，不能通过删真实持仓、版本、实验来消除矛盾。

### P1-12 AI设置提示与真实能力不符

设置页还提示“原型勿填真实key”“原型没有外部请求”，实际保存/连接功能已经绑定后台。属于过时说明，可能让用户误解操作后果。应准确说明本地保存、连接测试外呼和收费提交，避免页面写着原型却真实执行。此次没有填key或触发连接测试。

### P2-01 左侧筛选首次出现延迟

统一界面要等fragment和完整数据请求后才完成初始渲染，存在几秒空白。隐藏旧表仍被重复渲染，较大证据载荷也增加开销。应先呈现静态筛选框架/明确加载态，再填数量；避免同一轮重复重绘隐藏旧表。草稿已覆盖这些路径，浏览器性能与冷启动仍待验收。
