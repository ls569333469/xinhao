# EXP-0002 用量没解析到就记“未知”，并保存原始响应

- 条目ID：EXP-0002
- 版本：v1
- 来源报告：report-4dbefb0c984d40879ee9161e80edc9f2
- 经验：每次真实调用都要把供应商原始响应（不含密钥/请求头）存到报告目录，再从中解析用量；解析不到写“未知”，不能写 0；推理用量只记录，不再重复加到总量。
- 适用条件：所有真实模型调用（chat / responses / gemini 风格字段）。
- 状态：试用
- 证据：R3 报告 usage=unknown 的原因是旧代码把用量写死为 unknown 且未保存原始响应，事后无法补回。R4 已改为结构化解析并保存 vendor_response.json（见 iteration-research-r4-con-usage-evidence.md）。
- 反例：暂无。
