# 投研经验文件（当前文件阶段，不是页面功能）

> RES-20：本目录是**当前文件阶段**的经验记录，不是页面功能，程序**不会**自动读取这些条目，也不会改变默认提示词或生产投研规则。是否在某次投研中试用某条经验，由用户/执行人显式选择，并在该次任务记录里写明条目 ID 与版本。

## 文件格式

每条经验一个 Markdown 文件，文件名 `EXP-编号-简称.md`，开头固定字段：

| 字段 | 含义 |
|---|---|
| 条目ID | 如 EXP-0001，永不复用 |
| 版本 | v1、v2…；改内容就升版本，旧版本写在“修订记录” |
| 来源报告 | 产生这条经验的报告/任务 ID（可多个） |
| 经验 | 一句话说清楚该怎么做 |
| 适用条件 | 什么时候用；什么时候不适用 |
| 状态 | 试用 / 停用（只有这两种；没有“稳定有效”，需跨 3–5 个项目回顾后另定） |
| 证据 | 支撑这条经验的文件路径或数据 |
| 反例 | 出现过的反例；没有写“暂无” |

规则：行情数字、支撑位、解锁数字只属于历史案例，不当成下个项目的现时事实；同一问题补案例，不重复造规则。
